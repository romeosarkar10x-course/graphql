# Game — jshell speedrun

**Module 0 game** · **Grading:** auto (score printed) · **Needs:** internet

Print `A New Hope`, SWAPI film 1's title, fetched live, in as few lines of jshell as possible.
JDK only. Score = lines of code (comments, blanks, `/exit` excluded); ties break on characters. Par: 2.

```bash
bin/course start m00/05
cd workspace/m00-orientation/05-jshell-speedrun && ../../../bin/course jshell speedrun.jsh
bin/course test m00/05          # prints your score
```

**Solo:** beat par, then beat your own character count three times.

**Group:** 15-minute round. Everyone submits `speedrun.jsh`; one person runs `bin/course test m00/05`
on each and appends to [games/leaderboards/jshell-speedrun.md](../../../../games/leaderboards/jshell-speedrun.md).
Shortest wins; a reading of the winning entry out loud is mandatory.
