# Hints, scavenger hunt

1. In the docs pane, start at the root `Query` type and click through. Every field shows its arguments and type; a trailing `!` means non-null, and for arguments it means required.
2. Click a type name to open it. Enums list their values; object types list the interfaces they implement near the top.
3. For Q6, open `Issue`, list its interfaces, then open the likely one and check it declares `closed`. For Q7, open the connection type `search` returns and look at the type of `nodes`.
