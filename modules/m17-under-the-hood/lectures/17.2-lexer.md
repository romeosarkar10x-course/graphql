# 17.2 The lexer

## Hook (2 min)

`{ a b }`. graphql-java parses it as `{ a b }`. The spec says it is not a document at all. Who is right, and
how would you ever find out without writing a lexer?

## Concept (20 min)

### Source text and ignored tokens

A document is Unicode text (`SourceCharacter`: any Unicode scalar value, September 2025). Between tokens the lexer
skips the **ignored** tokens (2.1.6): the byte order mark U+FEFF, white space (tab and space), line terminators
(LF, CRLF, CR), comments (`#` to the end of the line) and commas. Nothing else: U+2028 is not white space.

### Tokens

`Punctuator` (`! $ & ( ) ... : = @ [ ] { | }`), `Name`, `IntValue`, `FloatValue`, `StringValue`. In Java 25 that
is a sealed interface of records:

```java
public sealed interface Token {
    int line(); int column();
    record Punct(String text, int line, int column) implements Token {}
    record Name(String value, int line, int column) implements Token {}
    record IntValue(String text, int line, int column) implements Token {}
    record FloatValue(String text, int line, int column) implements Token {}
    record StringValue(String value, boolean block, int line, int column) implements Token {}
    record End(int line, int column) implements Token {}
}
```

A `switch` over a sealed type is exhaustive: the compiler tells you when you forget a variant.

### The rules that catch people

- **Greedy, with lookahead**: `IntValue` may not be followed by a digit, `.` or a name start: `0x1`, `1.`, `00`
  are errors, not two tokens.
- **Escapes**: `A`, and since RFC #849 `\u{1F600}`. Two fixed escapes that form a surrogate pair are one
  character; a lone surrogate is an error.
- **Block strings** (2.10.4): `BlockStringValue()` splits on every line terminator, removes the common indent from
  every line but the first, trims blank lines at both ends, and joins with LF.
- **Positions**: lines and columns from 1. Columns count code points: a document with an emoji earlier on the line
  shifts every column after it by one, not two.

### Differential testing

The best oracle for a lexer is another lexer. graphql-java's (ANTLR) on 1,000 documents gives you 1,000 test cases
for free. When the two disagree, the spec decides, and sometimes graphql-java loses. In 26.1: block strings keep
CR; whitespace-only lines shorter than the indent keep their spaces; a lone CR does not start a line;
U+2028 and U+2029 are skipped.

## Check

1. Why is `1.` an error rather than `1` followed by `.`?
2. What is the value of `"""\n    a\n      b\n  """`?
3. Why count columns in code points?

<details><summary>Answers</summary>

1. `IntValue` has `[lookahead != {Digit, ., NameStart}]`, and `.` is not a punctuator on its own.
2. `a\n  b`: the common indent is 4, the first and last blank lines go.
3. The spec defines a document as a sequence of Unicode code points, and error locations refer to them; Java's
   `String` uses UTF-16, where one code point can be two chars.
