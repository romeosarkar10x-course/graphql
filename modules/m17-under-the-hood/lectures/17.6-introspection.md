# 17.6 Introspection and printing

## Hook (2 min)

Every IDE, codegen tool and gateway you used learns the schema by sending one big query. Introspection is not
magic: it is ordinary types and ordinary resolvers, over the schema itself.

## Concept (15 min)

### The types

Section 4.2 defines them in SDL: `__Schema`, `__Type`, `__Field`, `__InputValue`, `__EnumValue`,
`__Directive`, and the enums `__TypeKind` and `__DirectiveLocation`. Your engine parses that SDL like any other
and adds two root meta-fields, `__schema` and `__type(name:)`, plus `__typename` everywhere (4.1).

Details that matter:

- A `__Type` is either named (`kind` OBJECT, SCALAR...) or a wrapper (`LIST`, `NON_NULL`) with `ofType`.
- `includeDeprecated: Boolean! = false` filters fields, arguments, enum values and input fields.
- `defaultValue` is a **string of GraphQL**, `"[1, 2]"`, not JSON.
- `specifiedByURL` for custom scalars, `isOneOf` for `@oneOf` inputs, `isRepeatable` for directives.

### Printing

SDL printing is the reverse of parsing for the type system: definitions in order, descriptions (a string on one
line, a block string over several), applied directives, defaults; built-ins left out; `schema { }` only when the
root types are not named `Query`, `Mutation`, `Subscription`.

### Round trips

A good test of both: SDL → schema → print → parse → same schema; schema → introspection → SDL → same schema. What
cannot come back through introspection: applied directives other than `@deprecated`, `@specifiedBy` and `@oneOf`,
and extensions as separate definitions (they are merged). graphql-java's `IntrospectionResultToSchema` also drops
`@oneOf` and argument deprecations (course finding), so the lab compares your rebuild with graphql-java's own.

## Java build (25 min)

Lab 17.6: introspection resolvers and the SDL printer; four round trips on three schemas.

## Experiment (10 min)

Introspect graphql-java's version of the reference schema and yours side by side. List every difference and decide
which side the spec supports.

## Check

1. What does `__type(name: "[Book]")` return?
2. Why is `defaultValue` a string?
3. What is lost in SDL → introspection → SDL?

<details><summary>Answers</summary>

1. `null`: `name` is a type name, and wrappers are not named types.
2. A default can be any input value, including input objects and enums; GraphQL syntax prints it unambiguously,
   JSON could not tell an enum from a string.
3. Custom applied directives, extensions as separate blocks, and formatting; descriptions and deprecations come
   back.

</details>
