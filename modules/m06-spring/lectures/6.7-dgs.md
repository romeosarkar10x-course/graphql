## Concept (15 min)

DGS 12 (12.1.1 here; the plan said 11) is a programming model on top of Spring for GraphQL:
`@DgsComponent`, `@DgsQuery`, `@DgsMutation`, `@DgsData(parentType, field)`, `@InputArgument`, and
**codegen**: Java types, builders and `DgsConstants` generated from the SDL.

| | Maven |
|---|---|
| Netflix's codegen plugin | Gradle only |
| `io.github.deweyjose:graphqlcodegen-maven-plugin` 3.11.0 | `generate` goal, `schemaPaths`, `packageName`; add `target/generated-sources` with build-helper |

Found in lab 6.7: DGS 12.1.1 declares graphql-java 25.0, Boot 4.2 manages 26.1, Maven picks Boot's, and
the app dies at startup with `NoClassDefFoundError: graphql/schema/idl/DirectiveInfo`. Pin
`<graphql-java.version>25.0</graphql-java.version>`; Spring for GraphQL 2.1.0 runs on it. Two frameworks
on one engine: the slower one sets the engine version.
