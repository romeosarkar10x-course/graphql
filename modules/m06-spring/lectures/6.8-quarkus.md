# 6.8 Quarkus and MicroProfile GraphQL

## Hook (2 min)

There is no schema file. Quarkus generates `/graphql/schema.graphql` from Java signatures, and dev mode
updates it 0.4 seconds after you save.

## Concept (15 min)

MicroProfile GraphQL (`@GraphQLApi`, `@Query`, `@Mutation`, `@Source`, `@Name`, `@Id`, `@NonNull`),
implemented by SmallRye GraphQL on graphql-java; Quarkus 3.40 (platform 3.40.1.2) here.

- **Code-first defaults are loose**: a `String id` becomes `id: String`, every object field nullable,
  until you add `@Id` and `@NonNull`.
- **`@Source`** adds a field to the source type; `@Source List<Club>` makes it a batch, one call per
  response (lab 6.8 counts them).
- **Build-time processing**: scanning and schema generation happen in the `build` goal, so the app starts
  in about 0.33 s on the JVM.
- **Dev mode** (`mvn quarkus:dev`): measured "Live reload total time: 0.423s" after editing a `@Query`
  method (`_workbench/2026-11-21-m05-probe/quarkus-dev-mode.txt`).

The SmallRye typesafe client (a Java interface that becomes a GraphQL client) is the client half;
Module 12 builds clients.

## Java build (20 min)

## Check (3 min)

1. How do you make SmallRye emit `id: ID!`?
2. What turns `currentBook` into one call for all clubs?

<details><summary>Answers</summary>

2. A `@Source List<Club>` parameter returning a list in the same order.
