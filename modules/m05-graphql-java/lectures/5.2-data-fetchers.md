# 5.2 Data fetchers in depth

## Hook (2 min)

A three-level query on Shelfie calls 17 fetchers. You wrote six of them. Lab 5.2 prints all 17.

## Concept (15 min)

### What a fetcher is handed

`DataFetcher<T>.get(DataFetchingEnvironment env)`. The spec calls it a resolver with four inputs:
the parent value, the arguments, the context, and info. In graphql-java:

| Spec | `env.` | Scope |
|---|---|---|
| parent value | `getSource()` | what the parent field's fetcher returned (a record, a map, anything) |
| arguments | `getArgument("first")`, `getArguments()` | this field; schema defaults already applied |
| context | `getGraphQlContext()` | the whole request (viewer, tenant, loaders) |
| — | `getLocalContext()` | this branch: set by an ancestor's `DataFetcherResult` |
| info | `getExecutionStepInfo()` (path, type, parent), `getSelectionSet()`, `getField()` | this field |

### Default fetchers

A field with no registered fetcher gets `PropertyDataFetcher`, which reads a record component, getter,
public field or map key with the field's name. `Club.name` needs nothing; `Club.owner` needs a fetcher
because the record holds `ownerId`.

### Returning more than a value

`DataFetcherResult` carries `data`, `errors` (partial success: the value **and** what went wrong) and a
`localContext` for the children. `booksById(ids: ["b2", "zz"])` returns `[Piranesi, null]` plus one
error whose path is `["booksById", 1]`.

## Java build (20 min)

Lab 5.2: a call tree of every fetcher, `viewer` from GraphQLContext, `roleInClub` from local context,

## Experiment (15 min)

Read the tree's order: each field's value is completed before its next sibling is fetched, but all of a
list's items' fields come before their children. That is graphql-java's choice, not a spec promise.

## Check (3 min)

1. Which fetcher reads `GraphQLContext` and which reads local context: "the viewer" or "the club this
   member list belongs to"?
2. `Club.members(first: Int = 10)` and the query omits `first`. What does `getArgument("first")` return?

<details><summary>Answers</summary>

1. Viewer: GraphQLContext (request-wide). The club: local context (per branch).
2. `10`: defaults are applied during argument coercion, before the fetcher runs.
