# Game — REST or GraphQL?

**Module 1 game** · **Grading:** rubric (solo) or points (group)

20 scenario cards in [cards.md](cards.md). The skill is naming **the trade-off that decides it**, not
reciting that GraphQL is flexible.

**Solo:** `bin/course start m01/07`, fill in `picks.md` in 30 minutes, then `bin/course grade m01/07`.

**Group (3–8 players, 2+ teams):** shuffle the cards. Draw one per round; each team has 60 seconds to pick
a style and argue it in one sentence. The other teams may challenge: name a scenario detail the pick
ignores. Scoring: 2 points for the strongest trade-off named (judged by the non-arguing teams, or by an
AI judge with `solution/model-answers.md`), 1 for a successful challenge. First to 15.
