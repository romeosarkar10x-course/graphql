# Game — Debate: "Our bank should go GraphQL-first for its public API"

**Module 1 game** · **Grading:** rubric

**Solo:** `bin/course start m01/08`, write both sides and a verdict in `debate.md` (word limits in the
file), then `bin/course grade m01/08`. Optional sparring: ask your AI agent to argue the side you find weaker,
and rebut it in writing before you write your verdict.

**Group (4+ players):** two teams, sides drawn by coin toss. 3 minutes opening each, 2 minutes rebuttal
each, 1 minute closing each. The audience (or an AI judge using `rubric.md`) votes on arguments, not
eloquence. Then swap sides and argue again: the real test is whether you can make the case you disagree with.
