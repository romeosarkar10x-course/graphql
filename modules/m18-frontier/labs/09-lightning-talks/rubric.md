# Rubric: 18.9 Lightning talks (TALK.md)

Pass mark: 6 of 10.

| Points | Criterion |
| --- | --- |
| 2 | One clear idea, stated in the first 30 seconds and again at the end |
| 2 | A concrete example: a real request and response, or the tool run on real data |
| 2 | Correct and dated: stage or version, read on a stated date, from sources listed |
| 2 | Fits in five minutes: 600 to 750 words of script, at most five slides |
| 2 | Honest limits: what is not settled, what the tool does not do, when not to use it |
