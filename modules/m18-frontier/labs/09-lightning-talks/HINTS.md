# Hints: 18.9 Lightning talks

1. Write the one sentence you want people to remember first. Every slide either supports it or goes.
2. Five minutes is one problem, one idea, one example. The example is the talk: a request and response under
   the proposal, or the tool doing one thing on Shelfie's data.
3. Rehearse with a timer twice. Cut the part you rushed, not the example; end on the stage or version and the
   date, so the audience knows how fresh it is.
