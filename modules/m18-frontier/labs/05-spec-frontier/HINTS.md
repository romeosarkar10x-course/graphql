# Hints: 18.5 Where the spec is heading

1. The tracker's "All RFCs" page lists each proposal with its stage; open RFCs have a number (the pull request in
   graphql-spec), and older ideas without a pull request have a name (`FullSchemas`, `CompositeSchemas`).
   Several proposals have superseded versions; take the live one.
2. For the HTTP one, the old RFC document in graphql-over-http's `rfcs/` folder says where persisted documents
   went. Follow that link and check whether it is on the main branch and in the September 2026 edition's text.
3. For the reading, a pull request's "Files changed" tab is the spec diff: read it with the September 2025
   edition open beside it, algorithm by algorithm. The explainer is easier after you can state the change in one
   sentence for a client and one for a server.
