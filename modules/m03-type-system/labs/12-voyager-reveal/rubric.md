# Rubric, game 3c (10 points)

| Criterion | Points | Full marks |
|---|---|---|
| Honest sketch | 3 | A sketch exists, was clearly made before the reveal (it has mistakes or gaps), and marks roots |
| Scoring | 2 | compare.md counts are consistent with the sketch and the real schema |
| Missed types | 2 | Lists the missed types and says why each was invisible from the queries written so far |
| Cycle question | 2 | Names a real cycle with its shortest loop and links it to unbounded depth |
| Mutation-only types | 1 | Names the payload, error and input types only reachable from Mutation |

Pass: 7/10. A low score with an honest sketch can pass; a perfect sketch drawn after the reveal cannot.
