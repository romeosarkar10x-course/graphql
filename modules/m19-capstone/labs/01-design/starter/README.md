# My capstone

This repository is your capstone: one product, built across four stages and shown on demo day. The course's
brief is `modules/m19-capstone/README.md`; `capstone.json` tells the checker where everything is
(`modules/m19-capstone/contract/MANIFEST.md`).

Stage by stage: `bin/course test m19/01` ... `m19/04`, and `bin/course grade m19/NN` for the rubric parts.
Commit as you go: `workspace/` is a git repository, and `bin/course checkpoint 19` tags it at the end.
