# 2.6 Introspection

## Hook (2 min)

Point GraphiQL at an API you have never seen and it autocompletes every field. Nobody gave it a schema
file. It asked the server, in GraphQL, using fields that start with two underscores.

## Concept (12 min)

### The meta-fields

| Field | Where | Returns |
|---|---|---|
| `__typename` | Any selection set | The concrete type's name: `"Club"`, `"Query"` |
| `__type(name: "Club")` | Query root | One `__Type`: kind, fields, args, interfaces, possible types |
| `__schema` | Query root | Every type, the root types, all directives |

### Types describe types

A field's `type` is a `__Type` too. Named types have a `name`; wrappers have a `kind` of `NON_NULL` or
`LIST` and an `ofType`. So `members: [User!]!` arrives as

```
NON_NULL > LIST > NON_NULL > OBJECT User
```

and a query must nest `ofType` three levels deep to reach the name. The standard introspection query
nests it many levels for this reason.

### How GraphiQL builds its docs

It sends the standard introspection query once, gets a few hundred kilobytes of JSON, and rebuilds the
schema in the browser. graphql-java does the same in Java:

```java
String query = IntrospectionQueryBuilder.build();
Document sdl = new IntrospectionResultToSchema().createSchemaDefinition(data);  // JSON -> SDL AST
GraphQLSchema schema = UnExecutableSchemaGenerator.makeUnExecutableSchema(new SchemaParser().buildRegistry(sdl));
System.out.print(new SchemaPrinter().print(schema));
```

### Introspection evolves

Measured 2026-11-21 (`_workbench/2026-11-21-m02-probe/type-counts.txt`): graphql-java's default query
asks for `isRepeatable`, `isOneOf`, deprecated arguments and input values. SWAPI, AniList and
Rick and Morty reject it (`Cannot query field "isRepeatable" on type "__Directive"`); a query with
those options switched off works. Clients cannot assume the newest meta-fields.

| API | Types (including built-in scalars) | Standard query |
|---|---|---|
| Shelfie reference | 14 | accepted |
| Countries | 13 | accepted |
| Rick and Morty | 17 | rejected, legacy works |
| SWAPI | 58 | rejected, legacy works |
| AniList | 188 | rejected, legacy works |

### Should production expose it?

Public APIs (GitHub, Shopify) do: their schemas are documentation. Private APIs often turn it off and
publish the schema to a registry instead, because introspection is a map for attackers (Module 10).
