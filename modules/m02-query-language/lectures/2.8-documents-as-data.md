## Concept (12 min)

### From text to tree

```
text --Lexer--> tokens --Parser--> AST (Document) --Validator--> --Executor--> response
```

The AST is ordinary Java objects. graphql-java's `Parser.parse(text)` returns a `Document` whose
definitions are `OperationDefinition` and `FragmentDefinition`; selection sets hold `Field`,
`FragmentSpread` and `InlineFragment` nodes.

### Visitors

Instead of writing recursion by hand, subclass `NodeVisitorStub` and override what you care about:

```java
new NodeTraverser().preOrder(new NodeVisitorStub() {
    @Override
    public TraversalControl visitField(Field field, TraverserContext<Node> context) {
        int depth = 1 + (int) context.getParentNodes().stream().filter(n -> n instanceof Field).count();
        return TraversalControl.CONTINUE;
    }
}, operation);
```

`AstTransformer` does the same but lets you replace nodes (`TreeTransformerUtil.changeNode`), and
`AstPrinter.printAst(node)` turns any tree back into text.

### Three traps, found while building lab 2.8

| Trap | Symptom | Fix |
|---|---|---|
| `NodeTraverser.depthFirst` calls the visitor on enter **and** leave | Every count doubled | `preOrder`, or check `context.getPhase()` |
| The traverser visits each node *instance* once | A fragment spread twice is counted once after expansion | `selectionSet.deepCopy()` per spread |
| `AstTransformer` walks into nodes you insert | A fragment cycle expands until `OutOfMemoryError` | Detect cycles first (depth-first search over spreads) |

### What to measure

Depth, field count and alias count, **after** expanding fragments: the flat and fragment versions of
lab 2.4's query measure the same (depth 4, 54 fields), because they are the same request.
