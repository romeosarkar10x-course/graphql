# 2.7 Documents and hygiene

## Hook (2 min)

Production dashboard: 40,000 requests a minute to `POST /graphql`, p99 up. Which screen is slow? If
every operation is anonymous, nobody can say. Names are the cheapest observability you will ever add.

## Concept (12 min)

### A document holds many definitions

A document may contain several operations and fragments. The server runs exactly one operation:

| Request | Result (graphql-java 26.1 via Spring for GraphQL 2.1.0) |
|---|---|
| Two named operations, no `operationName` | `Must provide operation name if query contains multiple operations.` |
| Two named, `operationName: "B"` | Runs B only |
| `operationName: "B"`, but no B in the document | `Unknown operation named 'B'.` |
| `{ hello } query B { hello }` | `LoneAnonymousOperationViolation : Operation 'B' is following anonymous operation` |

### Descriptions on operations (September 2025)

The new spec grammar is `OperationDefinition : Description? OperationType Name? ...` (RFC #1170), so
this is legal GraphQL now:

```graphql
"The compact card in the club list."
query ClubCard($id: ID!) { ... }
```

graphql-java 26.1 rejects it: `Invalid syntax with offending token '"..."' at line 1 column 1`
(`_workbench/2026-11-21-m02-probe/probe-parser.txt`). Until it catches up, this course writes the
description as a `# Description:` comment.

### Request `extensions` (RFC #976)

The request body may carry `extensions`, a JSON object for things that are not part of the document:
persisted query hashes, client name and version, tracing flags. Unknown keys are ignored; a non-object
value is HTTP 400 from the reference server.

### Hygiene rules for this course

1. One named operation per file, named after the screen or job: `ClubPage`, not `Query1`.
2. Values in variables, never in the document.
3. Select what the screen shows, nothing more.
4. Fragments named after the component that owns them.
5. Files validated against the schema in CI (Module 13 makes this automatic).

## Check (3 min)

2. Name two things that read the operation name.
