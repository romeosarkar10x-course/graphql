My goal here is to introduce something with as few additional moving parts as possible. It's intended to be simple rather than robust. The primary new mechanism is being able to mark an SDL Directive definition as metadata and exposing such directive usages via introspection. Given an introspection result you should be able to re-create the SDL with directive usages in the right places. The main downside is that the introspection encoding is simple to the point of requiring post-processing. There is no explicit sub-selection; all metadata gets exposed in introspection. The metadata is not in a structured JSON form, but in arrays of named groups - however this more clearly maps to the way directives are being used.
