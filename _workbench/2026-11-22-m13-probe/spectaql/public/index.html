Queries

book

Description

A book by id, or null when there is none.

Response

Returns a Book

Arguments
Name Description
id - ID!

Example

Query
query book($id: ID!) {
  book(id: $id) {
    id
    title
    authors
    isbn
    publishedYear
    averageRating
    reviews {
      ...ReviewFragment
    }
  }
}
Variables
{"id": "4"}
Response
{
  "data": {
    "book": {
      "id": 4,
      "title": "abc123",
      "authors": ["abc123"],
      "isbn": "xyz789",
      "publishedYear": 987,
      "averageRating": 987.65,
      "reviews": [Review]
    }
  }
}
Queries

books

Description

All books in catalogue order. titleContains filters, ignoring case; first caps the list.

Response

Returns [Book!]!

Arguments
Name Description
titleContains - String
first - Int Default = 20

Example

Query
query books(
  $titleContains: String,
  $first: Int
) {
  books(
    titleContains: $titleContains,
    first: $first
  ) {
    id
    title
    authors
    isbn
    publishedYear
    averageRating
    reviews {
      ...ReviewFragment
    }
  }
}
Variables
{"titleContains": "xyz789", "first": 20}
Response
{
  "data": {
    "books": [
      {
        "id": "4",
        "title": "xyz789",
        "authors": ["abc123"],
        "isbn": "xyz789",
        "publishedYear": 987,
        "averageRating": 123.45,
        "reviews": [Review]
      }
    ]
  }
}

Mutations

createReview

Description

Rating 1 to 5, one review per user per book. Rule violations come back in userErrors.

Response

Returns a CreateReviewPayload!

Arguments
Name Description
input - CreateReviewInput!

Example

Query
mutation createReview($input: CreateReviewInput!) {
  createReview(input: $input) {
    review {
      ...ReviewFragment
    }
    userErrors {
      ...UserErrorFragment
    }
  }
}
Variables
{"input": CreateReviewInput}
Response
{
  "data": {
    "createReview": {
      "review": Review,
      "userErrors": [UserError]
    }
  }
}

      "book": Book
    }
  }

Types

Book

Description

A book in the catalogue.

Fields
Field Name Description
id - ID! Stable identifier, e.g. b1.
title - String! Title as printed.
authors - [String!]! Authors in credit order.
isbn - String ISBN-13, when known.
publishedYear - Int Year of first publication.
averageRating - Float Mean rating rounded to 2 decimals, null when there are no reviews.
reviews - [Review!]! Newest first. last caps the list.
Arguments
last - Int
Example
{
  "id": 4,
  "title": "abc123",
  "authors": ["xyz789"],
  "isbn": "abc123",
  "publishedYear": 123,
  "averageRating": 987.65,
  "reviews": [Review]
}

Types

Club

Description

A reading group.

Fields
Field Name Description
id - ID! Stable identifier, e.g. c1.
name - String! Display name.
description - String What the club reads and how it meets.
owner - User! The member who runs the club.
members - [User!]! Members in join order. first caps the list.
Arguments
first - Int
memberCount - Int! How many members the club has.
currentBook - Book The book the club is reading now, if any.
meetups - [Meetup!]! Meetups in date order; only upcoming ones unless upcomingOnly is false.
Arguments
upcomingOnly - Boolean
visibility - Visibility! Who can see the club.
createdAt - String! When the club was founded, ISO 8601.
Example
{
  "id": "4",
  "name": "abc123",
  "description": "xyz789",
  "owner": User,
  "members": [User],
  "memberCount": 987,
  "currentBook": Book,
  "meetups": [Meetup],
  "visibility": "PUBLIC",
  "createdAt": "abc123"
}

Types

ID

Description

The ID scalar type represents a unique identifier, often used to refetch an object or as key for a cache. The ID type appears in a JSON response as a String; however, it is not intended to be human-readable. When expected as an input type, any string (such as "4") or integer (such as 4) input value will be accepted as an ID.

Example
"4"
Types

Int

Description

The Int scalar type represents non-fractional signed whole numeric values. Int can represent values between -(2^31) and 2^31 - 1.

Example
987
